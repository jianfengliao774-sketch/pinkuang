# 本轮金额与收益展示修正（2026-09-30）

用户本轮要求金额保留五位小数，替代先前的三位展示要求。历史上线记录保留当时事实。本文件记录源码修正和本地验证，不表示已完成线上发布。

- BNB、BEM、日产能价格、通知金额、公开记录和收益图默认显示五位小数；使用整数四舍五入，不经浮点数转换。
- 极小非零值显示 `<0.00001`，避免把正数显示成零；Gas 上限向上取整至五位，避免低估最高费用。份额、矿机数、区块和编号仍为整数。
- 显示精度不改变交易金额。运营表单失焦可显示约数，重新聚焦恢复原始金额；预览可展开精确募集金额。手工输入和自动报价均保留原值。
- 移除运营募集输入失焦时写回舍入值、预算项目表单把预算改为三位数的旧行为。项目预算仍按精确 wei 验证正值及单机上限，后续合约参数校验保持独立。
- 多矿机项目收益明确请求 `portfolio` 口径。只有来源 Factory/Market、父项目、账户、时区、日期窗口、BEM 精度均匹配时才展示；单矿池 `pool` 响应不能冒充父项目收益。父项目只统计实际收到的 BEM，不重复加入子矿池归集。

验证包括 51 项金额/报价/通知/公开记录/表单单测，以及独立本地浏览器审查：七个主页面、父项目收益、桌面和 390px 手机、手工输入焦点切换和未签名预览。示例 `48.065004999999999900` 展示 `≈ 48.06500`，聚焦恢复原输入，预览保留精确值。另有收益口径验证、错误来源拒绝、零收益恢复的浏览器回归。所有浏览器请求使用合成链数据，未调用真实签名或交易发送。
