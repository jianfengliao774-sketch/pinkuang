# 官网市场完整批量读取复核（2026-09-28）

本轮覆盖预算项目和原单机/keeper 共用的官网市场发现路径。所有核验只使用公开 `eth_call`、代码及区块查询，没有签名或广播交易。

## 完整性与依赖

原单机发现只重新读取官网 JSON 中已知的活跃挂单，且目标系列超过 1,000 条即拒绝。该方式无法证明 JSON 没有漏掉旧挂单。当前 `official-market-discovery.mjs` 完整枚举固定区块的 `1..nextListingId()`，在链上读取价格后再按系列、预算、矿机模型、已验证权重、纯挖矿和非最优条件筛选。一个矿机先保留最新挂单，再判断价格，避免高价新挂单使旧低价挂单重新出现。官网快照仍用于原有时效及枚举边界保护，接口旧字段继续保留；新增 `coverage`、`chainListingsScanned`、`chainHash` 表示实际覆盖。

扫描设历史 100,000 条、目标系列活跃 10,000 条上限。任何超过上限、缺失响应、RPC 异常、取消、链变化或固定区块 hash 变化都会失败；失败不能解释为“官网无货”并转入 Firsto。

批量读取固定使用 Multicall3 `0xcA11bde05977b3631167028862bE2a173976CA11`。每次初始化检查 BSC chainId 与 runtime hash；每批末尾调用 `getBlockNumber()`，要求与请求的固定块相同；只接受完整成功结果且限制响应长度。

其 runtime 为 3,808 bytes，keccak256 为 `0xd5c15df687b16f2ff992fc8d767b4216323184a2bbc6ee2f9c398c318e770891`。2026-09-28 在 BSC 固定块 **124446363**，`bsc-dataseed.bnbchain.org` 与 `bsc.publicnode.com` 的代码、区块 hash、链 ID 和块号调用结果一致；字节码也与官方仓库预签部署交易中的 runtime 逐字匹配。固定来源：[部署记录](https://github.com/mds1/multicall3/blob/b667d67ecfa5361a81e8f110234ce242613b0012/deployments.json)、[部署交易](https://github.com/mds1/multicall3/blob/b667d67ecfa5361a81e8f110234ce242613b0012/README.md)。

复现用 bytecode 与来源记录保存在 `deploy/scripts/fixtures/multicall3-bsc-runtime.json`，不是任意可替换的聚合器配置。各批仅执行 `eth_call`，不构造签名或广播请求。

## 测试与真实读取边界

`official-market-discovery.test.mjs` 保留原有 8 项保护，并增加遗漏旧单、1,100 条活跃、去重后价格判断、完整历史上限和固定块重组 5 项，共 13 项。聚合器独立测试覆盖固定代码来源、跨批次顺序、并发上限、错误链/代码、失败或缺项/多项响应、错误块号、取消和超大响应。

原单机只读实测固定块 **124447465**（hash `0x3fcb076b99e09290ea35552a4933536077afd8d6fb7206018438ded1bb317676`）：完整扫描 **21,016** 个历史 ID，读取 TapeOut 活跃挂单 **250** 项，价格范围内检查模型 **179** 项，共 **45** 次 `eth_call`；512 项/批、8 路并发时耗时 **29.44 秒**，最终区块 hash 保持一致。测试使用指定 taskId=42，返回 0 个匹配项只代表此模型，不代表整个官网没有可买矿机。

批量参数的调整需继续以真实公共节点结果验证，不把减少 RPC 请求数直接等同于提速。上述数据是源代码 SHA-256 已记录的一次只读运行；后续源码或参数更改应另记验证结果。完整扫描会超过原页面 20 秒等待时间，也挤占原接口 30 秒上限，HTTP 交互须配合有界只读任务及轮询；在轮询返回完整且仍有效结果前不能开放采购预览。

服务器路由测试仍需在支持 0700 私有数据库权限的 Linux 环境执行。Windows 因既有权限保护拒绝启动，不应为通过测试而放宽它。本轮不表示已完成主网真实购机或已发布生产服务。
