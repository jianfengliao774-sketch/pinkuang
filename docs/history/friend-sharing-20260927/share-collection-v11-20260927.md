## 加载预算与分享链接

每张提供 3 个版本：640×336 手机 WebP（≤60 KiB）、1200×630 桌面 WebP（≤130 KiB）、1200×630 下载 JPEG（≤220 KiB）。9 张海报共 27 个文件，均通过预算校验。8 张新图手机实际 28,144–60,538 字节，JPEG 实际 145,458–221,574 字节。

600px 以下屏幕固定使用手机版，包括 DPR 3 的 iPhone 视口。随机结果确定前不挂载图片；打开分享只加载所选海报，不下载整套，不预取高清 JPG。用户保存时才请求高清版。新增 `scripts/share-artwork-check.mjs`，纳入 `pnpm check`，防止后续遗漏文件或超出预算。

Telegram 和 X 接收的是带海报标识的独立静态链接，例如 `/share/anime.html?mode=demo&project=16928&source=tg`。9 个静态页面在原始 HTML 中直接提供对应海报的 Open Graph/Twitter 图片；用户打开后进入原矿机详情。正式项目仍使用池地址识别，演示只允许已知编号。目标只允许本站固定路由，未知参数、重复参数、外部跳转、Factory/钱包注入均拒绝。

社交按钮预填文字与链接，图片附件仍可由用户保存后添加。未代用户发帖；平台是否展示链接卡及缓存刷新由 Telegram/X 决定。
