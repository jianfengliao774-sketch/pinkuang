## 三、关联的收益到期机制：需要单独决定

这里不能把“收益失效”直接认定为链上销毁；本轮也未审计合约。但以下现行文案仍延续收益逾期不可领取的设定：

| 位置 | 当前文案或元素 | 建议方向 |
| --- | --- | --- |
| 首页 → 按份分享真实产出 | 查看每笔收益与到期时间 | 改为查看每笔收益与领取记录 |
| 已连接资产总览 → 待办事项 | 一笔收益即将到期；0.1638 BEM · 剩余22小时 | 如取消失效机制，改为有收益待领取，不显示逾期警告 |
| 收益中心标题说明 | 把每一笔产出、领取和到期时间看清楚 | 改为“把每一笔产出与领取记录看清楚。” |
| 收益中心警告条 | 0.1638 BEM 即将到期；请在指定时间前领取 | 如取消失效机制，删除警告条 |
| 收益批次说明、表头、状态 | 到期后该批收益不可领取；到期日期和时间；即将到期 | 如取消失效机制，移除到期列和相关状态，保留记账日期、我的收益、领取状态 |
| 权益归属说明 | 转让不会重置历史收益的到期时间 | 保留“份额转让前的已归属收益仍归原持有人”，删去到期说明 |
| 参与规则第03条 | 开启到期机制的项目按批次计算有效期 | 如取消失效机制，删去这句，保留24小时领取间隔 |

建议业务口径：已归属收益保留，符合领取间隔后可领取，不设置逾期销毁或失效。此项属于建议，尚未替用户确定或实施。

募集截止、投票窗口、整机挂牌有效期均属于其他业务时限，不应按“收益到期”一并删除。

## 五、残留原因和修改边界

前一次调整更新了主要分配比例，但首页说明、共用演示流水、公开记录统计与筛选、CSV、翻译字典和冻结审查组件尚未同步清理。应该按这些共享来源处理，不能仅在某个页面隐藏文字。

对应源码：

- web/components/SiteOverview.jsx:31：首页说明。
- web/components/Platform.jsx:51、72、91：表格、统计、筛选、CSV和详情弹窗。
- web/lib/demo-data.js:14：销毁演示流水。
- web/lib/platform-stats.js:7：未在当前首页使用的 burned:5.4089 字段。
- web/lib/home-en.js 与 web/lib/platform-en.js：当前和旧版销毁相关中英文键值。
- web/components/PlatformMobileReviewV7.jsx、web/lib/mobile-review-v7-scenarios.js：最新手机审查快照及 A12 场景。
- web/components/PlatformReview.jsx、web/lib/review-scenarios.js：旧审查快照和场景。
- web/public/review-files/：旧/新下载清单和索引。

本次不涉及合约、后端、真实资金或链上历史的改动；也不能以页面清理替代合约销毁逻辑审计。
