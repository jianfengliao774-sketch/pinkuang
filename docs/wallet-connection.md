# BEMine 钱包入口与首个项目

## 钱包连接

首页的钱包入口先打开选择弹窗。仅在用户选择具体钱包后调用该 provider 的账户授权；不会在钱包发现、页面读取或恢复历史交易时申请签名。

服务端输出的连接按钮初始禁用，本地事件绑定和钱包发现初始化完成后启用，不等待任何 RPC。这样避免首次打开页面、React 初始化前的点击丢失；桌面和手机的首击回归还人为挂起只读 RPC，验证连接入口与数据加载解耦。

浏览器钱包优先使用 EIP-6963 公告，同时兼容已有 EIP-1193 注入和多 provider 列表。实际已检测的钱包与下载入口分别标注；网站不能承诺检测不到的钱包已经连接。

账户授权后，如果当前网络不是 BSC 主网，向同一个钱包请求切换到 chainId 56。仅在钱包明确返回未知网络（4902）时请求添加 BSC；拒绝、已有待确认请求、其他错误均不自动重试。添加后仍需切换，并重新核对网络与账户。连接不请求 personal_sign，也不发送交易。

手机端在钱包内置浏览器中使用相同注入连接流程；普通手机浏览器通过已核验的钱包官方入口打开本站。WalletConnect 跨设备扫码需要本项目自己的 Reown projectId；未配置时不显示可用的扫码连接，不使用第三方项目凭据。

钱包图标与手机打开入口的具体来源记录在静态资源旁的说明文件中。链参数依据 [BNB Chain 官方钱包配置](https://docs.bnbchain.org/bnb-smart-chain/developers/wallet-configuration/)，切换/添加流程依据 [MetaMask 官方网络管理文档](https://docs.metamask.io/metamask-connect/evm/guides/manage-networks/)。

## 为什么还没有可认购项目

2026-09-27 08:26 UTC 的只读核验中，部署的 Factory `0xcB24E7F96D81037086A268d6ea63c53f91D412A2` 在主网块 `124300533` 返回 `poolCount() = 0`，已追平的索引也返回 0 个矿池。这是尚未创建第一期项目；不能从加载期间无 source 的状态推断项目未开放。

08:32 UTC 再次在固定区块 `124301304` 核对：`creationPaused() = false`，`operator() = 0x6F4d78fB59eC938cBAF65b9fc822aD04d00c155E`，`poolCount() = 0`；读取结束后复核区块哈希一致。因此当时不是建池暂停，也不是运营钱包配置遗漏。

创建项目入口位于“运营工作台”，仅向链上登记的运营钱包提供建池操作。填写已核对的矿机、募集金额和期限后，先预览，再由用户在钱包中确认。创建矿池只支付 Gas；成员的认购资金在后续认购时进入矿池。前端发布不会代替用户创建矿池或签署任何交易。

页面应分别显示核验中、读取失败、已读取但尚无项目、筛选无结果和无个人持仓，避免把暂时的数据不可用误报为矿池数量为零。

## 下单响应

认购、挂单和买入保留完整的同区块预览、最新状态重读、金额绑定、余额/Gas/nonce 校验、服务器持久化确认和一次性签名许可。优化只把独立的读取并行执行；所有已启动读取结束后才允许保存意图，失败不自动重试。确认时去掉登录流程内的一次重复待处理记录读取，发送服务仍在本次请求中独立读取 session 和待处理记录。

固定每次请求人工延迟 100ms 的测试结果（不是生产速度承诺）：

| 阶段 | 原耗时 | 优化后 | 保留的读取 |
|---|---:|---:|---|
| 认购预览 | 1425ms | 774ms | 13 次 RPC |
| 挂单预览 | 1633ms | 871ms | 15 次 RPC |
| 买入份额预览 | 1868ms | 879ms | 17 次 RPC |
| 发送服务进入至请求钱包交易确认 | 1001ms | 666ms | 12 次钱包读取、4 次日志 HTTP |

最后一行的 HTTP 使用模拟服务，不含真实服务器完整合约校验与用户确认时间。生产服务器只读合约校验三次实测 955/770/740ms；初始保存意图和签名许可会分别做一次，未跳过。实际耗时仍受钱包节点、本站网络和用户确认影响。

界面在用户确认后立即显示阶段：钱包登录、最新交易信息、余额与费用、订单确认、发送前检查、钱包交易确认。首次操作的登录签名和交易签名分开提示。拒绝或未知发送结果不显示交易已提交，不自动重发。

普通订单、治理和运营共用一个同步的界面提交锁，避免同一事件循环的重复点击越过 React 的异步 busy 状态。只有持有本次提交锁的操作才能清除进度和忙碌状态；服务器的单次签名许可与钱包级交易锁仍独立生效。

本轮校验：149 项前端单元测试通过；桌面/手机钱包选择 6 场景、下单 9 场景、首次点击 2 场景通过。全部钱包及交易回归使用受控模拟，未在真实钱包中批准连接、签名或发送主网交易。生产只读验收检查当前静态发布、钱包弹窗、7 个图标、手机 HTTPS 打开入口和空矿池状态。
