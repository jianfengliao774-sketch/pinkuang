# 资产加载、运营权限与报价辅助

2026-09-27。此改动只发布前端，不改变已部署合约或服务器交易权限。

资产总览原先先完整读取项目目录，再读取持仓和记录。目录读取期间索引推进，会导致后续接口来源不一致、整个页面重试。本轮将首屏所需接口同时发起，所有读取结束且身份、区块、时间与安全覆盖一致后才一次呈现。分页仍绑定既有 source，失败不冒充零。现场复现原版连接后约 16 秒才显示真实空持仓；固定每请求 100ms 的同一 adapter 测量中，加载阶段从 3382ms 降到 2185ms，三条索引请求的发起窗口从 1855ms 缩小至不足 1ms。这不是生产网络延迟保证。

运营入口只向当前具体 provider、账户和部署配置已核验的运营钱包显示。未连接、非运营、权限读取中或失败均不渲染运营组件和部署入口；刷新或换钱包立即撤销旧授权展示。直接访问 #operator 只有受限提示。真正的操作仍由现有链上权限和签名前检查约束。

运营方可以直接检索 Firsto 报价、选择矿机，系统核对官方系列、持有人、活跃状态、任务及纯验证权重，并在固定区块读取官网 listingFor。选择后自动填入精确募集总额和购机上限，默认可调整额外预算 10%、募集 24 小时、购机 48 小时；预览和发送前重新获取、核对，不自动签名。

指定矿机方案使用链上官网市场价格，不能使用 Firsto 买方总额替代。灵活购机方案沿用已交付的日产能参考公式；Firsto 签名/批量订单在当前部署中仍仅供参考。用户后续要求 Firsto 合约采购和矿机唯一项目，它们需要单独的合约实现、测试及升级，不能因为此报价功能发布而宣称已支持。

报价与链上核对超过五分钟、持有人或条件变化、非官方矿机、无效挂单等情况阻止生成或继续使用草稿。自动数据不能代替运营方确认募集条件。JSON 已移至高级导入，空值和截断格式显示中文提示。

本次真实只读例子：TapeOut #16516，官网挂单 17762，链上价格 0.041 BNB；默认 10% 募集预算生成 0.0451 BNB 总额。该例子只验证数据通路，不构成选择建议，未创建项目或购买矿机。

验证：167 个前端 Node 测试通过；权限浏览器 8 场景、原运营/治理 3 场景、自动报价 4 场景通过；19 个静态页面构建及旧 ABI 校验通过。12 个 Linux 后台日志测试在 Windows 的既有 0700 权限前提处失败，未降低权限要求来绕过；后台代码本轮不变，远端 Linux CI 独立记录。所有浏览器交易步骤均使用受控 mock；真实网络只读核验没有签名或发送。
