# 报价显示、用户挂单与新合约接入（2026-09-28）

本轮用户要求：持有人从朋友设计的前端直接挂单；隐藏未验证矿机；检查日产能价；所有金额与产能固定显示三位小数并四舍五入。源码整合仍在 `codex/contracts-v2-integration`，保留两仓设计及既有资金保护。

## 显示和计算

- BNB、BEM、美元、预计日产能、每日产能报价与市场参考价使用整数运算四舍五入至三位。显示小于 0.0005 的正数会成为 `0.000`；可领/可售状态、金额校验仍判断原始整数，不把该显示当成零余额。
- 既有手工填写募集金额的三位规范化沿用用户此前选择；本轮不顺手改动这一输入规则。自动行情与订单精度不受它影响。
- 份数、矿机数、编号、区块等计数仍为整数。交易参数、执行上限、费用计算、排序、导出记录保留全部原始精度；不把格式化字符串反向传入交易。
- 报价页新增“本机日产能价”：`卖家挂单 Wei × 10^8 ÷ 本机预计日产 BEM atomic`，单位为 BNB /（BEM / 日）。它不是整台售价，也不是另一台矿机的同型号参考价。
- 实测 TapeOut #2465：40 / 5.62896 = 7.106（显示值）；Behemoth #2562：13.343616 / 1.71072 = 7.800。因此前者按日产能价排在后者前是正确的。
- 市场参考价保持来源的独立快照和有效期。截图 `8.024042950513538748` 显示为 `8.024`，不改变原始参考值或筹款计算。

## 矿机过滤与挂单

报价源在上游分页前指定 `miningStatus=verified`，本站再排除混合权重、最优、未启动及无效字段。分页总数与快照保留来源含义，不以当前页的有效行数伪造全市场总数。来源报价的“纯验证池”标识不等于订单已完成交易授权；购买前仍须链上核验、模拟与签名。

普通持有人无需管理员代挂单。资产总览和份额市场中的本人持仓增加直接挂单入口，自动选择项目并显示本人持有、锁定、可售份额；预算项目的挂单表单直接呈现。发布仍由持有人钱包确认，未知交易结果禁止重发，出售投票冻结与锁仓限制保留。
