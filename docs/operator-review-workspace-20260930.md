# 运营工作台：申请查看与独立板块

正式前端在同一个运营工作台内切换「发布项目」「审核」「领取手续费」。仅挂载当前板块；发布与采购、申请列表、手续费操作各自读取数据。合作方 `codex/v4-product-launch` 的钱包、缓存、五位金额及项目目录改进均保留。

审核列表按单机和预算项目分页读取当前轮出售候选，显示矿机、提案编号、申请人、精确价格的五位展示、市场参考价、双过半投票进度和审核状态。管理员选择一条申请后即可签名批准或驳回，不再手填审核编号和价格。参考价维护放在审核板块的折叠工具内。

列表使用现有正式索引发现项目，按索引区块核对项目登记、申请、参考价和审核状态；RPC 并发最多四个。项目读取失败单独提示，不冒充空列表。预算申请人的交易与回执不能核实时明确显示未知。仅当前轮候选出现在此列表，不宣称覆盖已归档的历轮历史。

已核验首批列表可缓存两分钟用于返回展示。可见页每三十秒更新当前分页，查看详情或处理交易时暂停轮询；刷新不会加载其他工作台板块。缓存不能直接授予审核权限，签名前只重新读取选中的申请，精确 wei 保持不变，不引入交易模拟。

验证：新增数据层十项、真实组件事件处理十四项回归；web 全量 580 项通过。覆盖过期与驳回、同轮已执行、失败隔离、钱包/部署隔离、重复点击、旧请求取消、参考价变化和分页刷新。审核复读与交易状态刷新同时发生时，旧动作取消且不会锁死按钮或解除新动作的锁。生产只读读取确认现有目录可用：单机 0 个、预算项目 1 个，当前轮申请均为 0。该检查未发送签名或链上交易。

此次更新仅涉及前端。合约、部署清单和现有五个后端角色不变。实际发布提交、CI 验签与线上结果在发布完成后记录。
