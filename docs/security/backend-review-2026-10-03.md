2. **首页重复读取：成立。** 原实现即使命中展示缓存，也在每个请求中重新检查 index、signer 就绪状态和最新区块。现将展示就绪状态纳入同一轮合并刷新，缓存期间访客不再触发上述请求。实际交易权限仍走独立实时验证，展示缓存不授予签名权限。
3. **短期 RPC 故障/闲置会丢失展示：成立。** 原展示快照两分钟失效。已验证快照现在最多保留一小时，仅供展示，并保留原时间和 stale 标记；过期快照明确禁止作为交易就绪证明。链身份变化、规范链哈希变化、未知验证错误仍立即作废。无人访问两分钟后停止展示定时刷新，避免把保留期延长变成持续收费轮询。首次冷启动仍需成功验证一次。
4. **display/SSE 路由限流缺项：生产配置已核实。** v5 location 直通 indexer，bemine HTTPS 父级未配置相关 limit_req/limit_conn。新增每 IP 展示请求 20/s、突发 40；SSE 每 IP 16 条、全站 64 条连接，超限返回 429。使用连接源地址，不信任访客自报 X-Forwarded-For。不做线上压力/DoS 测试。
