# 参与拼矿统一项目列表与灵活建池修复

已于 2026-09-30 08:36 UTC 随前端 `d91b1e2` 发布；后台保持 `4986715`。来源证明、最终 CI 和线上只读验收见 [v4-unified-records-release-20260930.md](v4-unified-records-release-20260930.md)。下文候选预检按发生时的状态保留。

用户要求多矿机项目直接出现在“参与拼矿”，不再显示独立的下方预算项目区域。

单矿机和多矿机父项目共用一个表格、状态筛选、搜索、排序、已加载计数和“加载更多”。两类读取仍各自保留来源、分页和取消机制；多矿机项目只算一个项目、100 份，不能按其子矿机重复计数。募集筛选和计数均包含待购机阶段。编号、产能等尚未核对的值不伪造；父项目可以按项目地址或“多矿机”搜索，每份金额按精确 Wei 排序。

点击多矿机行进入现有 `#portfolio/<address>` 详情，重新读取当前合约状态，继续使用原认购、领取、退款、出售和签名逻辑。目录缓存不能赋予交易资格。单类读取失败时仍保留另一类项目，显示不完整状态及重试，不再误报“尚未创建拼矿项目”。普通用户页面移除了单独的多矿机区域；其他权益、运营与治理页面的入口不变。

运营工作台“单台矿机灵活替代”中的 `Use an exact bigint or unsigned decimal string.` 来自报价导出的 `extraBps` 和 `referenceObservedAt` 为 JavaScript number，而合约编码入口只接受精确整数。这两个元数据在网页报价适配边界先检查非负安全整数及 uint16/uint64 范围，再转为十进制字符串；高级导入采用相同处理。价格、Wei、日产出等资金字段仍只接受原严格类型，未放宽编码器或修改实际金额。

验证：6 项统一目录单元测试、6 个统一列表真实浏览器检查（混合展示、两个游标、搜索排序、详情、部分失败恢复、手机宽度）；24 项报价/运营单元测试与 4 个灵活建池浏览器场景（电脑/手机、自动报价/原格式导入）。浏览器使用本地合成合约和报价，没有主网签名、发送或 journal 写入。

这是前端更新，不部署或升级合约。旧站仍应保持 410、旧服务 inactive/disabled；正式运行及旧版退役基线见 [v4-release-and-legacy-retirement-20260930.md](v4-release-and-legacy-retirement-20260930.md)。发布时须验签新产物并核对后台兼容性，不能为前端样式调整重启旧服务。

## 金额显示沿用用户确认的三位规则

共享金额、BEM 产能与参考价显示恢复为三位小数，用整数计算四舍五入；不足显示精度的非零权益显示 `<0.001`。这修正了后续前端整合中遗留的五位默认值。募集输入的显示仍以原精确值为来源，界面近似数不能回写报价或 calldata。Gas 费用上限使用三位向上取整，避免少报上限。可编辑出售报价的联动输入和实际交易精度不在本次显示修复中调整。

2026-09-30 的 `3d9e4c2` 已通过完整 CI、验签及 clean Git 配对核验，并在服务器完成只读兼容预检；尚未切换该静态包。用户随后增加公开记录中文说明的要求，因此最终发布会重新绑定包含记录说明与三位显示的提交。不得把 3d9 的预检记成已上线。

## 公开记录说明

公开记录和多矿机项目历史共用双语操作说明。42 种真实索引事件全部覆盖：例如 `PortfolioCreated` 显示“创建多矿机项目”，并显示该事件实际记录的预算和项目地址。认购、退款信用入账、实际领取、购机、收益归集、出售提案、挂牌、成交及份额转移按各自 ABI 解释；未记录的金额、操作者或交易结果不推断。未知事件仍可查看原始事件与交易。原始 CSV 保留所有事件及精确字段，不因页面说明或三位显示而改变。

最后本地定向单测 60 项通过。浏览器检查包括目录 6 项、灵活预览 4 项、Authority/用户自付退出 7 项和记录 5 组（中文、英文、手机、CSV、项目历史）。全部使用本地合成链和钱包；真实主网交易不在这些测试的通过声明内。记录解释已独立与索引 allowlist 和合约发射点逐项核对。
