# 对 `380412e` 审计报告的整改记录

范围：审计报告《拼矿 BEMine：代码安全、业务可实现性与前后端适配审计》中的 F01–F08。本文记录源码和测试层面的整改；**不代表代码已在 BSC 主网部署或存量池已升级**。部署地址、实际管理员、运行时代码、旧池数量和移动钱包行为仍须在目标环境核验。

| 项目 | 源码处理 | 验证与边界 |
| --- | --- | --- |
| F01 旧票低价售矿 | 提案创建时原子记录当前份额和成员数，立即冻结份额变更；旧格式提案不能投票、执行或成交，过期后可重新提案。Lens 当秒读当前冻结持仓，过秒读历史检查点。 | `AuditGovernance.t.sol`、`PoolVoting.t.sol`、`PoolLens.t.sol` 覆盖同时间戳交易后票权和旧提案阻断。该修复已在本次整改分支的基线中。既有主网合约是否已升级未核实。 |
| F02 正式页面仍演示 | 新增独立 `/live/` 链上工作台，不让演示账户参与真实交易。网页从完整服务器事件索引发现池/订单，再按同一区块重读 Factory、Lens、PoolVault、ShareMarket；支持 100 份认购、募资撤回、任何人归集、本人领 BEM/池内 BNB、份额挂牌/买入/撤销/过期解锁/市场 BNB 领取、并列出售提案/投票/执行/整机购买。精确 wei 和完整地址参与交易编码。 | 同源 API 必须持有匹配当前产物摘要的部署清单、完整部署记录和运行时代码/升级图校验；否则页面无可签名目标。SQLite 保存钱包交易意图，浏览器只保留表单临时输入。上线还需完成真实部署、索引服务、反向代理、桌面/移动钱包小额全流程验收；静态演示首页及尚未实现的质押/质保模块不能当作真实服务。 |
| F03 旧审查文案 | 可访问审查册已改为当前 99% 成员收益、1% 平台费、无销毁、无领取冷却、永久保留收益及整机出售 1% 费；构建前执行可达审查页文案检查。 | `web/scripts/review-policy-check.mjs` 加入 `pnpm check`。尚未把审查册重构为与正式页面完全同一组件，后续改规则仍需同步审核文案。 |
| F04 旧账迁移 | 增加只读、固定块、完整枚举的 BSC 旧池预检和操作说明，旧 checkpoint、到期制、部分扫描、未知状态均阻止升级放行。保留合约原有安全拒绝，不清零或重算历史债权。 | `deploy/scripts/legacy-pool-preflight.test.mjs` 覆盖错误网络、代码哈希、遗漏池、旧账与数据不一致。仓库无经验收的现役 Factory 地址，**不能执行生产旧池预检，也没有声称已完成复杂旧账迁移**；发现旧池后需逐池审计并另做迁移方案。 |
| F05 部署/交易恢复 | 部署台支持丢哈希补录、同 nonce 加速/撤销、规范链最终性和实际 Gas 账；`/live/` 把矿池、市场、治理操作写入同一服务器意图表。准备态可无 Gas 放弃；已准许签名的未知交易只能补录哈希或用同 nonce 自转撤销，达到 finalized 且回执归属匹配后解锁。 | 部署恢复测试、网页发送/拒签/跨标签/SQLite 重启/替换取消和最终性测试。目标 BSC RPC 若不支持 finalized，意图保持待确认，不能自动误判成功。 |
| F06 跨页报价 | Firsto 代理有界校验并放行 `viewId`，精确矿机查找仍校验快照一致性；页面报价不能提高链上参考限价。 | `deploy/src/pricing.test.ts` 覆盖跨页、快照漂移与非法标识。 |
| F07 少数份额抢提案窗口 | 保留全池七天一轮和 24 小时份额冻结；同轮允许不同持有人各提交一个价格候选，共享开轮时的份额快照和截止时间，各候选独立投票，先通过并执行者挂牌。旧格式轮次不能接入新候选。 | `PoolVoting.t.sol` 与 invariant 覆盖少数开轮、多数另提价格、60 份折价门槛和单次执行。`/live/` 枚举本轮所有候选，而非只展示开轮提案。若多数持有人未在 24 小时内行动，仍须等下一轮；这是保留的治理时限。 |
| F08 依赖公告 | 网页 Next 升至 16.3.6，部署工具 tmp override 升至 0.2.7，并更新锁文件。 | 网页和部署目录依赖审计已无报告项；根目录开发依赖仍有无法由现有上游提供补丁的低危 elliptic 转依赖，未作为运行时消除声明。构建与测试已重跑。 |

`/live/` 的服务器部署、数据库权限、同源路由和启动条件见 [`web/server/LIVE.md`](../web/server/LIVE.md)。旧池预检见 [`docs/legacy-pool-upgrade-preflight.md`](legacy-pool-upgrade-preflight.md)。对外页面还需在有效的 BSC 部署记录、事件索引和真实钱包环境下做小额验证；当前整改没有替用户发送任何签名或资金交易。用户已选择单钱包治理、无销毁、严格结清和单钱包最多可持有全部 100 份，这些选择未在本轮改变。
