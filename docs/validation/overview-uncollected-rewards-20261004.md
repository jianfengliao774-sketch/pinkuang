# 资产总览待领取 BEM 展示

此前待归集 BEM 只接入收益中心，资产总览卡片和矿机列表仍展示索引已入账余额。资产总览现复用同一只读 reader、钱包/部署身份边界和缓存。

卡片及桌面/手机的每行同时显示预计待领取、已入账与单矿机待归集。单矿机使用同块已入账与净待归集金额，避免把归集前的旧 pending 与归集后的 booked 重复相加；多矿机仅计父项目已入账，并明确标注待归集收益见项目详情。组合总额并不声称多矿机父项目也在同一块读取。

汇总采用统一资产范围，先排除重复及父项目内的子池。`scopeRows` 保留已加载但尚未显示的零余额行，读取失败保持未知；经验证的新 booked 展示投影在过滤前应用，保留零份额历史收益。原始持仓与交易权限不被预计金额覆写。

pending 只在资产总览及收益中心读取已加载单矿机。切换页面共享 30 秒缓存，手动刷新和确认交易强制更新，币价、索引/SSE及页面计时器不触发新 pending 读取。
