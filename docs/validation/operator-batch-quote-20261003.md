# 5181 挂单报价与建池原因修复

2026-10-03。范围为正式站报价展示和拒绝原因；不启用批量采购，不替换或升级已部署合约。

## 真实问题

TapeOut #5181 的缓存详情返回一笔 open Firsto `circuit_batch_ask`，没有另一笔单笔订单。卖价 1.37377728 BNB，含费价 1.3875150528 BNB。它使用批量市场 `0x3f58c9cbce933c76158b2a29b0d612c46546dc43`、schema 1，即使只有一片叶也必须采用批量协议。

界面详情错误地只取可执行路线价格，批量单被采购解析拒绝后，真实报价也随之显示为 —；“没有挂单”的描述则掩盖了真实原因。当前合约 `FlexiblePurchase.buyFirsto` 明确只执行 kind 0 / SignedAsk V2，解除按钮限制无法购买此批量单。

## 改动

- 有效、未过期的公开挂单价保留在详情，日产能价按原始价格和日产出精确计算；没有执行路线时明确标为挂牌参考。
- 官网可执行单仍优先显示并生成方案，不被 Firsto 参考报价覆盖。
- 批量单明确说明订单存在、现合约不支持采购；指定建池保持禁用并说明原因。已有“单台矿机灵活替代”模式可使用其型号/产能参考，募集后实际采购仍须满足合约条件。
- 关闭、非 Firsto、批量及未知订单分别返回准确错误，不把所有情况都归为批量。
- 未增加 API 查询或付费 RPC；公开报价不进入可执行固定建池上限。
