# 正式版回归测试（2026-10-03）

本轮检查当前新正式合约、网站和后台。发现两项网页问题并修复：行情请求失败会清空尚未过期的报价；普通矿机详情页读取没有展示用途的治理数据。发布仅替换静态网页，后台进程、合约地址和资产保持不变，未重置索引数据库和签名记录。

## 修复与回归

1. **币价有效缓存丢失。** 原报价有效期 60 秒，一次 HTTP 错误、网络超时或无效响应会立即清空显示。修复后保留原报价与原始更新时间，失败不会延长有效期；原报价过期后显示不可用，后续有效报价恢复显示。仍每 15 秒刷新、显示两位小数。回归直接执行实际 `BemPriceStat` 组件，覆盖三种失败、过期和恢复。
2. **详情页多余治理读取。** 普通资产、记录和参与者标签页没有使用非 Listed 矿机的治理快照。详情组件发起的治理读取改为仅在整机 Listed 状态且非投票标签时执行；投票组件保留自己的读取。测试覆盖普通状态不读、Listed 仍读、状态变化能触发、投票组件的读取归属。

## 份额与整机出售

测试确认投票进行中不能转移或成交份额，同一秒的转移不能重复计入投票快照。整机处于 Listed 或已成交 Closed 状态时，份额卖单不能成交；允许取消卖单，取消只解锁份额。真实整机成交后 Closed 状态永久拒绝份额转移和重复整机结算。

投票期结束、整机尚未执行挂牌而仍为 Active 时，份额交易可恢复。不能把上述检查表述为“发起提案后份额永久不能成交”。

## 线上后台与请求成本

六个服务运行，当前购机、挖矿心跳与进程 / 发布版本对应；索引完整且追平 observedSafeHead，行情 JSON 正常。发布网页前后核对服务 InvocationID 和重启次数，网页更新不重启后台。

产品图展示缓存为 45 秒，刷新采用合并请求；缓存访客回归确认没有额外 RPC。最近访问超过两分钟窗口后，定时任务不再主动发起产品图链上刷新。空项目 worker 不查询 Firsto 候选列表；它仍进行发送就绪所需的图谱、Gas nonce 和旧发送记录最终性核验，因此不宣称后台没有 RPC 开销。本次测试没有强制刷新链上证明或新增收费扫描。缓存访客的零额外 RPC 结论来自请求计数回归，未核对服务商账单。
