# 下架项目的参与人提醒与退款入口

公开项目目录继续隐藏有完整归属证据、且原卖家已经不再持有的指定矿机项目。个人资产、收益中心和原详情地址使用个人持仓数据，不使用公开目录过滤。链上归属变化不证明有偿成交，提示为“目标矿机已转移给其他持有人，本项目已下架”；未知证据、灵活参考矿机和矿池自己购得目标均不冒称被他人买走。

参与人的退款说明和操作入口复用同一展示模型：

- Funding：撤回全部认购后，本金进入待领取 BNB；确认后再由本人领取。
- Funded：保留个人本金与实际 `purchaseDeadline`，到期前说明等待条件；索引区块时间达到期限后才展示可用的开启退款操作。操作准备仍重新核对链上状态。
- Refunding：待领取 BNB 与领取入口继续保留。撤回后份额为零并不删除未领取款项。
- 未知余额不显示“已退款”，未到期不承诺立即退款。当前生效合约未增加提前退款能力。

通知中心与铃铛提醒由当前钱包已加载的个人持仓派生，项目地址可直达现有详情和退款入口，不依赖 Telegram 绑定，不发送外部通知。首次进入正式站并连接钱包只读取已有物化持仓缓存；非个人页面在 60 秒内复用同账户缓存，已有页面刷新事件会在缓存过期后更新提醒，手动刷新立即更新；不增加定时器或逐池读链。

后端无需新增运行接口或重启：`targetAvailability`、个人本金、购机期限与 BNB 信用已经存在于物化持仓结果。新增 HTTP 回归验证个人结果不受公开隐藏影响，不向其他钱包串入余额，HTTP 读取不增加 RPC。

本次发布范围为静态前端展示和既有退款入口，链上状态和退款期限以当前生效合约为准。发布证据在同名目录中补充。
