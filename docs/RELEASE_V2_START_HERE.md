## 部署操作

1. 用装有钱包扩展的 Chrome/Edge 打开已验收的新部署台，确认页内是 16 笔、BSC 56，并核对上述版本。
2. 选择钱包。连接授权后，页面会请求一次本站操作日志的无 Gas 登录签名；它与后续链上交易不同。
3. 检查地址和 Gas 预算，运行只读预检。预检通过后再按页面流程逐笔确认，保持同一钱包只使用本次部署入口；不要同时运行旧站操作、keeper 或其他发交易程序。
4. 钱包拒绝、网络中断、加速或取消后，先用原交易/替换交易哈希核对。没有最终回执时不重新建计划、不删除日志。
5. 全部确认并核验两套合约图后，导出完整部署记录和公共清单。不要手填模拟地址，不用旧清单凑齐预算字段。

## 小额功能测试顺序

先完成只读地址、角色、矿机和报价核对，再由用户选择实际矿机与小额预算：

1. 单机建池、最后一份并发限制、认购/撤回、到期失败退款。
2. 官网购机：资金从矿池转出、NFT 进入正确 Vault，购机余款记入原权益人可领取金额。同 NFT 第二次创建应失败。
3. Firsto 购机：检查准确 SignedAsk V2、卖家/签名/到期/nonce/feeEpoch 与买方总额，确认金额与 NFT 所有权后再看成功回执。
4. 多矿机预算：父项目认购，批准采购清单和上限；每台先建空子池、再由父合约购买。每笔均由钱包确认，结果不明先恢复。两笔之间子池被其他人认购时应停止，不能当成原子建购。
5. 收益归集与个人 BEM/BNB 领取，分别核对单机历史权益和预算份额转让规则。
6. 份额挂单、部分成交、撤单、到期和卖款领取；买卖双方各自费用及转让后的权益与记录一致。
7. 逐台整机提案、投票、执行、过期解冻和本站 Firsto 合约成交；同笔过户前结清 BEM，售款进入矿池/父项目账本后才领取。

Firsto 原生页面成交仍按已确认规则暂不开放。通知 bot、无人值守 keeper、质押和质保不因网页发布自动启用。测试记录必须区分本地模拟、固定块 fork、线上只读验收和真实钱包交易，不能互相代替。
