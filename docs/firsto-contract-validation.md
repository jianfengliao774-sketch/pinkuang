# Firsto 合约采购与矿机永久去重验收

日期：2026-09-27。此记录对应开发分支；没有发送主网交易或启用自动采购服务。

## 业务结果

- 募集完成后，池可调用固定 Firsto Signed Ask V2 合约购买原目标矿机，NFT 直接归池所有。池支付卖家价与 Firsto 费用；调用钱包只支付 Gas。
- 同一 Factory 中，同一官方矿机合约地址和 Token ID 永久对应一个项目。固定、灵活和带到期条件的所有建池路径共用登记；灵活采购实际买到的替代矿机同样占用。项目退款、结束或出售后不释放，两个并发交易也不能绕过。
- 旧 Factory 或登记迁移未完成时，前端和签名后台关闭新建入口。退款、提款和读取保留。登记在合约内强制执行，界面检查只用于提前提示。

真实分叉使用公开矿机 TapeOut #5788 和公开卖家签名，未替换外部协议代码、改写其存储或伪造矿机。真实池的含费支出为 0.0505 BNB，旧卖家结算 28421 原子 BEM，NFT 到池，订单 nonce 失效，0.0095 BNB 余款按现有规则归成员。测试证明该固定历史场景可执行，不保证该订单现在仍然可买。

构建固定 Solidity 0.8.24、Shanghai、optimizer 200、viaIR=false。Factory 运行时代码 24534 字节、Vault 24512 字节，仍在 24576 字节限制内，但余量很小。后续变更须继续检查大小，不得通过关闭限制来部署。
