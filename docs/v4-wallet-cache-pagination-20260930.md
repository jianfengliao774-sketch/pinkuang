# 钱包、缓存和公开记录改进（2026-09-30）

本轮更新依据用户测试反馈：钱包频繁断开、预算项目收益口径错误、切页重新读取导致空白、资产分开显示、记录需手工加载，以及最新金额五位小数要求。本文记录待发布源码与验证，线上发布时间另附实测结果。

## 用户行为

- 钱包重复通知相同账户/网络不清连接；短暂传输中断保留钱包及已核验展示，撤销旧预览、暂停交易，限次只读恢复。真正换账户、网络或撤销权限会断开。后台读取失败不代表钱包断开。
- 重新核验部署时保留此前配置和读取客户端，关闭操作权限；缓存有固定过期时间，失败或历史展示不会获得交易授权。
- 资产总览将单矿机与多矿机项目合并一表；父项目只计一次份额和项目收益，不重复计算子矿机。分页未完成时汇总明确为已加载部分。空持仓引导浏览项目，详情返回实际来源页面。
- 父项目详情缓存两分钟，按部署、工厂、项目、账户隔离。点击立即显示已有数据，后台核验后才能操作；临时失败保留展示和重试入口，重组清除缓存。
- 公开记录向下滚动自动加载，每个游标限一次自动请求。严格保留来源区块、游标排序、去重及取消旧请求检查；失败保留已有记录，显式重试，不能持续循环。
- 金额统一五位小数，保留极小非零金额提示。编辑框只切换约数展示与原始输入，不修改实际 wei。收益统计显式区分父项目 `portfolio` 与单矿池 `pool`。
- 收益中心明确单矿机统计范围，账户流水包含认购等操作，标题使用“已确认账户记录”。
