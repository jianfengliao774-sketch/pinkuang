# 购机只接受纯验证、非最优矿机

这次修复覆盖既有单机池的官网挂牌和卖家直购入口，以及复用这些子池的多机项目。此前灵活选机与 Firsto 入口已有质量检查，但固定矿机入口的共用 `PurchaseValidation._activeMinerKey` 只核对矿机身份和挖矿状态，可能购入含未验证权重或被标记为最优的矿机。

现在所有购机入口在付款前都要求链上 Mining 记录满足：`status == 1`、`optimal == false`、`unverWeight == 0`、`verifWeight > 0`。卖家历史收益结清和 NFT 转移可能调用外部合约，因此购买完成前还会在 `FlexiblePurchase._finish` 通过同一校验重新读取；任一条件变化，整个交易回滚，先前的收益结清、NFT 转移和 BNB 支出均不生效。前端报价及只读选机规划器原本已过滤这些矿机，链上限制不依赖页面或 keeper 的过滤结果。

运营页的手填官网挂单入口也在钱包预览前，以同一链上区块核对挂单所指矿机的质量；自动报价选机路径此前已过滤这些矿机。这一页面检查是旧合约升级前的操作拦截，最终资金保护仍以升级后的链上校验为准。

验证：`PoolPurchase.t.sol` 新增固定官网、直购、卖家收益结清期间及官网 NFT 转移期间的三类不合格状态回归；运营页新增手填官网挂单回归。Solidity 单元测试 445/445，部署控制台 256/256，产品前端 208/208；Slither 0.11.5 `--fail-medium`、24 项升级布局校验、源码绑定的部署产物与前端 ABI 校验均通过。本地检查不替代真实 BSC 市场的端到端验收。

这次修改只改变购机校验，没有修改存储布局。已部署的旧 Beacon 实现不会自动获得限制；需要部署新 `PurchaseValidation` 库和链接它的新 Vault 实现，按现有 48 小时治理延迟升级 Beacon，并核对链上字节码后才对现有矿池生效。本分支没有发送任何主网交易。
