# BEMine 中危与低危复核（2026-09-28）

本报告针对本次用户提交的审计清单。源码修复不等于 BSC 主网已升级；页面必须保持部署清单、实际实现代码和编译产物一致。尚未完成链上升级时，不得把本分支的新 ABI/摘要单独发布到当前 `/bemine-v2/`。

## 已修复

| 问题 | 处理与边界 |
| --- | --- |
| 预算出售提案被 1 份地址抢占 | 发起提案至少持有 10/100 份。每轮可提交至多 16 个候选并逐项投票；即使拆分全部 100 份，攻击者最多产生 10 个具备发起资格的地址，不能占满本轮候选位。非发起人仍可投票。页面同步显示门槛和候选。 |
| 建子池与购机之间被抢先认购 | Factory 创建带指定预算项目认购人的子池；子池 `deposit` 在链上只接受该项目。项目购机前核对 Factory 注册、指定认购人、空余额和矿机条件，在同一笔交易中认购 100 份并完成购机。外人不能插入 1 份导致后一步失败。之前创建的无指定认购人子池不能自动变成新子池，需逐个核对。 |
| Factory 更新金库后预算项目无法购机 | 子池仍必须来自指定旧 Factory；项目不再错误地要求新建子池的金库与项目创建时金库相同。项目自身的原金库结算不变。 |
| 未认证挑战写库、报价与归档写入、公开 RPC | 挑战在同钱包有效期内复用且无需写库；过期清理至多每分钟一次。挑战、报价、归档、RPC 加每客户端限流；报价记录至多 4 KiB、每钱包只保留最近 200 条。Firsto 报价额度经可信回环 nginx 的 `X-Real-IP` 按真实客户端区分。分布式攻击仍需要入口层限流、容量与磁盘监控。 |
| 旧 live-api 的全局挑战/会话上限 | 同钱包复用挑战，满额时淘汰最早的过期或最旧项；客户端限流先于全局分配。 |
| 极小份额交易手续费显示成 0.000 BNB | 份额市场钱包确认框保留至 18 位有效小数，精确 Wei 未改变。 |
| 零价挂单提示 | 部署台原已有免费转出勾选与钱包确认；预算项目页面新增免费转出勾选及确认框醒目提示。 |
| nginx 配置继承安全头 | v2 部署台及产品代理片段移除局部 `add_header`；后端本身返回 `Cache-Control: no-store`。静态页面及价格 JSON 改用 `expires -1`，不再覆盖站点级安全头继承。 |

## 保留或待现场处理

- **挖矿协议持续 claim 失败可能冻结份额转让或整机出售。** 合约目前坚持转让/出售前严格结清。用户此前明确选择保留此规则、不加紧急出售；本次尚未得到改变该选择的确认，所以未偷偷加入可能放弃待领收益的逃生口。这是未解除的可用性风险。
- **磁盘与 RPC 的分布式耗尽**不能仅靠单进程按 IP 限流彻底防住。入口 nginx 的准确 location、上游客户端 IP 传递、磁盘配额与独立 keeper RPC 仍需在实际服务器配置中核对后发布。现有请求限流是第一道保护，不应把它表述成抗分布式拒绝服务的保证。
- **`/live` 旧页**当前从同源经过摘要和代码哈希校验的清单取地址，登录签名检查固定 Origin、BSC chain ID、钱包、nonce 与到期时间；审计中“直接使用任意 API 地址、盲签”的描述与当前源码不符。但它仍是旧版入口，正式切换时应核对是否需要下线，避免两套页面混淆。
- **零价出售或低于 Firsto 市场参考价**沿用用户已确定的双过半及平台审核规则；本次没有改出售政策。
- **其余运维建议**（站点 CSP、控制台独立源、systemd 凭据、Telegram 绑定链接）已逐项记录于 [低危清单复核](security-low-risk-review-2026-09-28.md)。keeper 增加了凭据文件读取支持，但服务器 unit、产品 CSP、独立源与入口限流仍须以现网配置复核，不能只改仓库模板就宣称已在生产生效。

## 升级次序

新子池隔离依赖 `PoolFactory.designatedSubscriber` 与新版 `PoolVault.deposit`，预算项目还依赖新版 `BudgetPortfolioVault`。三个实现必须按既定 Timelock 流程协调升级，并通过新部署清单的代码哈希、ABI 和源码摘要校验。升级前保留当前已核验站点，升级后再发布配套页面；不得仅为消除“不一致”提示而修改清单。

编译器 `optimizer_runs` 由 200 调整为 1 以保持 EIP-170 运行体积上限；当前 Factory 24,516 B，距 24,576 B 上限仅余 60 B。后续新增 Factory 逻辑前必须重新核对体积，也应在实际网络观察 Gas 成本。
