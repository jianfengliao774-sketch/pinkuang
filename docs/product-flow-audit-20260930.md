## 已修正内容

- 父项目收益：服务端返回 `scope: portfolio`，旧客户端仅接受 `pool`，因此真实父项目收益被误报“收益数据口径无效”。现在父项目显式请求其口径，并核对 Factory、Market、父项目、账户、时区、日期、BEM 精度和整数金额。图表说明归集到父项目的实际 BEM，不重复合计子矿池收益。
- 金额展示：按用户本轮要求统一五位。BNB、BEM、日产能价、通知和公开记录采用整数四舍五入。极小非零值显示 `<0.00001`；Gas 上限向上取整。份额、矿机数和编号保持整数。
- 精确输入：募集金额和购机上限失焦显示约数，聚焦恢复精确原值；预览可展开精确金额。取消预览、焦点切换和五位显示均不更改合约使用的 wei。父项目表单也不再把手工预算改写为三位数。

主要源码变更：`web/lib/live-data.mjs`、`web/components/LiveYieldChart.jsx`、父项目历史读取中的 `scope` 参数、`web/lib/amount-display.mjs`、`web/lib/funding-amount.mjs`、`web/lib/operator-quotes.mjs`、`web/lib/portfolio-create-form.mjs` 和 `web/components/LiveOperator.jsx`。对应单测和既有浏览器金额断言随五位显示更新；历史部署说明未改写。

## 页面审查发现

| 页面或操作 | 实际问题 | 修正方向 |
| --- | --- | --- |
| 资产总览空持仓 | 复用目录空状态会误称全站尚未创建项目，并提供创建首个项目入口 | 改为当前账户无持仓或待领取权益，提供参与拼矿入口 |
| 从资产总览进入父项目 | 返回按钮固定回参与拼矿，丢失原来的页面上下文 | 保留进入来源，返回资产总览或收益中心 |
| 收益中心顶部统计 | 顶部数额只统计单矿机，下方又显示父项目权益，范围容易被误解 | 标题明确单矿机统计范围，父项目权益保持独立标明 |
| 收益中心历史表 | “已确认收益记录”中含认购等账户事件 | 改用涵盖这些事件的账户记录标题 |
| 父项目显示缓存 | 需要防止跨账户、工厂或部署复用，以及把部分读取当完整详情 | 增加隔离与完整读取单测；缓存仅为显示，不构成当前交易授权 |

上述页面改动已由主任务整合；本地复测确认父项目返回资产总览、单矿机统计范围和账户记录标题。没有发现 390px 手机视口的整页横向溢出；宽表使用容器内横向滚动。
