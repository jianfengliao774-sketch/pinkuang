# 页面加载与重试

基于已上线的 `0e92319`，保留最新前端设计与 BNB 三位小数输入。

首次部署核验失败时，页面提供“重新加载”；项目页面的“刷新”也会重新获取部署清单并核验。加载过程中禁用重复重试，旧轮结果仍受取消检查约束。重试只读取数据，不请求钱包登录、签名或发送交易。

URL 片段变动先比较解析后的页面与矿池身份。同一页面的等价片段变化不再作废正在进行的读取，避免 `#home` 改为 `#home/ignored` 后一直加载。切换到不同页面或矿池仍丢弃旧结果。

链 ID 和区块头改为并行读取，每次区块头核验减少一个串行网络等待。两个请求均结束后才继续；错链、错区块、代码摘要、部署关系、最终区块重组检查仍然保留。交易签名之前的确认与持久化顺序不变。

回归覆盖并行读取的失败排空、错误网络/区块、启动失败后手动恢复、等价片段下加载完成及真实切页时旧结果隔离。合约、ABI、部署清单与金额计算规则没有变化。
