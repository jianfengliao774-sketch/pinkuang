## 展示与恢复

钱包发现优先展示已识别 RDNS 的 EIP-6963 钱包，隐藏同品牌旧注入接口的别名；不同 EIP 实例和未知钱包仍保留。刷新钱包列表或晚到宣告不能替换正在授权的 provider。

后台暂未就绪的当前产品资料会有限次数重新核验，就绪后停止这轮重试。重试不得发起钱包授权或签名；切换账户/页面后丢弃旧结果；已有交易确认不被恢复流程打断。历史资料不能赋予管理员权限或直接用于交易。

隐藏技术卡片不等于取消核验：错误、重试入口、钱包确认和交易安全条件仍保留。领取、退款、撤单继续由用户钱包支付 Gas。合同代码、ABI、费用规则及旧站数据不因本轮前端修复改变。

建池预览的链上读取使用网站的只读节点，不依赖扩展钱包提供全部 RPC。纯读取要有期限、进度和重试反馈，迟到的预览不得弹出旧确认框；真正的钱包授权、签名或发送不得因读取超时而自动重复。报价的精确 Wei 与确认参数仍须重新匹配，不能为了加快弹窗跳过检查。

募集退款规则不作变更：`Funding` 状态的本人全部认购可通过 `withdrawDeposit()` 撤回，退款先记入本人可领余额，再通过 `withdrawBnb()` 提至本人钱包。单机池已经 `Funded` 后不能任意撤回，购机期限届满且仍未购机时使用 `finalizeFailure()` 开启退款。运营页“协议回收”是矿机管理入口，不是撤回募集款的入口。
