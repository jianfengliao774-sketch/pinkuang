# 本机日产能价修复

正式版项目列表此前误把 Firsto `asset.listingReference.dailyCapacityPriceWei`（同类参考价）显示在本机日产能价列，同时用于排序和详情侧栏。

修复后，Funding/Funded/Listed 使用该 NFT 当前公开卖单价格，Active 使用实际购机成本，除以同一 NFT 的 `mining.estimated24hAtomic`。挂牌价不包括买方手续费和募集预留金；实际购机成本包含实际已支付的费用。缺少本机价格时显示未知，不以同类参考、限价或募集预算代替。份额市场仍使用该份额挂单价格 × 100 ÷ 本机日产出，交易精确金额不变。

本机卖单限于详情返回的同一 collection/tokenId、当前持有人、BSC、未到期的 open ask；买单和其他矿机报价不参与。金额运算使用 BigInt，展示固定五位小数。缓存命名空间从 v1 改为 v2，旧参考口径缓存不会恢复到新页面。无新增请求或钱包发送步骤。
