# 认购阶段误判修复

`requireCurrentProductStage` 将当前服务 `operationalReady` 与页面预览时的值比较，并把不相等归为“链上产品阶段已变化”。钱包重新核对时页面会将该值临时遮蔽为 false；服务恢复为 true 后，即使部署身份完全相同，也会误报。新增回归测试在修改前复现了此错误。

修复只移除部署身份比较中的就绪位相等条件。部署阶段、产物摘要、工厂与市场地址、激活区块/哈希、管理员部署身份仍匹配固定清单。发送权限使用当前响应，由原有交易规范化和钱包账户/链号核对执行；后台恢复不会冒称部署变更。没有加入交易模拟、动态 Gas 估算或额外发送步骤。

验证：全部 677 项网页/API 测试通过。新增完整发送链路测试使用本地钱包与 journal 替身，覆盖从就绪 false 到 true 的恢复、50 份及精确 `55550000000000000` wei（0.05555 BNB），只调用一次钱包发送，不出现 `eth_call` 或 `eth_estimateGas`。另覆盖真正的激活哈希变化仍被拒绝。此发送测试不是主网交易。
