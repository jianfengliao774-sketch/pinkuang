# v3 公网部署台 Gas 凭据清理

本步骤只适用于已核对的 v3 公网部署台。它移除 v3 服务的 Gas 凭据挂载和 v3/v4 两份独立副本，不改原版 keeper 凭据、v2 服务、v4 服务、网站路由或链上状态。v3 Stage 2 目前已暂停；现役 v3 服务端对新的 Stage 2 签名意图要求 systemd 凭据，移除挂载并重启后继续拒绝签名。

在服务器上用 root 执行，先只读预检：

```sh
python3 remove-public-gas-credential.remote.py --dry-run
```

预检核对固定的 v3 unit 内容、唯一的凭据挂载、v3 Stage 2 服务端门禁、部署与激活日志状态、v2/v3/v4 服务状态、v4 进程实际环境、两份副本与原版内容一致，以及其他已安装的 systemd 单元没有引用这两份副本。任何差异都会拒绝执行，不应跳过检查。

预检通过后，在同一台服务器运行：

```sh
python3 remove-public-gas-credential.remote.py
```

正式执行只暂停并重启 v3 服务。它将原 unit 与两份副本暂存于 root 专有目录；若重启或后验失败，会还原 unit 与副本、重启 v3 并检查原状。后验包括 v3/v4 进程没有私钥来源、v2/v3/v4 服务正常、部署与激活日志未变化、v3 页面可访问，以及两份副本已离开原路径。**后验通过才进入清理提交阶段**：删除受保护的暂存目录。若最后的目录清理失败，脚本保留 v3 无凭据状态、返回错误并给出受保护目录位置，需人工核对残留；此时不会自动恢复公网私钥挂载。

本脚本不执行钱包签名或自动购机。v3 历史部署记录和旧版 v2 业务仍各自独立保留。
