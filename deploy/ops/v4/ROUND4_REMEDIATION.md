# 第四轮审计整改记录（独立正式版 v4）

依据 `00-summary-round4.md` 与 `ALL-bemine-round4-2026-09-29.md`。本记录只说明独立 v4 的代码与预创世部署台；旧 v1/v2 合约、页面和服务不参与新图配对。

| 审计项 | 当前结果 |
| --- | --- |
| R4-01 / F4-01 钱包调 Gas、加速、取消或同 nonce 替换后锁死 | 已修普通 EOA 的确定性结算与放弃入口；7702 内部调用仍需人工核对，不能猜测放行。 |
| O4-01 创世提交锁死后端 | 合约产物仍绑定创世提交；后端可在独立审查后按新源码提交演进，配对校验分别验证版本。 |
| R4-02 / F4-03 Stage 2 长间隔逐块回溯 | 改为最终确认锚点校验；Stage 2 仍保持服务器与页面双重暂停，等待真实链上流程验收。 |
| F4-04 部署无只读回滚预检 | 用户后续明确要求取消模拟；Stage 1 已移除应用层 `estimateGas`/交易 `eth_call`，仍固定经审核的 Gas 上限并核对 nonce、余额、费率和代码。此项审计建议不再满足：状态变化导致的回滚可能到钱包签署后才显现并消耗 Gas。 |
| S-v4 部署台公网暴露 | nginx Basic Auth 已作用于部署台页面、产物和 API；未认证请求为 401。 |
| O4-02 前后端包可自报来源 | 后端逐文件核对 Git；配对计划和禁用态安装器已加入。前端静态导出仍不能从仓库提交独立证明每个字节，**正式产品开放前仍须可信 CI 产物证明**。 |
| O4-03 构建遗漏跨目录脏源码 | v4 构建核对工作树与跨目录依赖，并从固定提交隔离构建。 |
| F-01 / F-02 / F-03 / F-04 / F-10 / F-11 / F-12 / F-13 / F-14 / F-15 | 修正索引短时同步、来源比对、失败分类、重组作废、按页面预览、服务器时间、历史读取和预算读取额度；v4 预算展示复用同一区块只读图证明。交易准备仍重新读链。 |
| R4-03～08 角色限额、keeper、RPC、公图、索引和签名 | 独立限额、延时复核、公平队列、按访问证明、索引版本重扫及过期签名取消已加入并测试。 |
| R4-09 购机锁记录截断 | v4 私有状态根使用稳定 flock inode 与持久 sidecar，只有能证明旧持有者退出时才自动修复。首次建锁至 sidecar 落盘间的崩溃仍须人工核对，不能删锁。 |
| R4-11 代理超时倒挂 | v4 部署台的未来 cutover nginx 草案改为 90 秒，长于私有 IPC 的 45 秒；当前 relay 仍禁用。 |
| v4 服务器展示缓存 | 独立索引的持久 SQLite 路径固定为 `/var/lib/pinkuang-index-v4/index.sqlite`；服务器已建立仅 `pinkuang-v4` 可访问的 `0700` 目录。公开历史分区可从同块已核验快照读取，交易、钱包余额和订单可成交性仍实时核链。新合约尚未创世，索引服务与缓存数据库均未启用或填充。 |

预创世部署台可以核对和准备部署，不能据此认定新合约已上链。`/bemine-v4/`、产品写入、Authority 代发、自动购机均保持关闭。正式开放还需真实创世与 Stage 2 回执、前端可信构建证明、独立索引追到安全链头及完整业务端到端验收。用户选择沿用原 Gas 钱包公开地址；公网页面进程不持有其私钥。旧版运维加固与路由不属于本次独立 v4 的变更。
