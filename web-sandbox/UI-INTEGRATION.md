# BEMine 主网出售测试入口

目标入口：`https://tapeout.cc.cd/bemine-sale-test/`。它是独立静态页面，默认首页和 `/bemine-v4/` 的资源、路由、配置及交易服务保持各自独立。

## 页面和流程

顶栏显示“整机出售测试”、`BNB 主网 · 模拟矿机`、当前钱包和“返回首页”。页面明确标注这套合约和 NFT 为本次测试使用，金额仍使用真实 BNB。金额统一显示五位小数，实际交易使用原始精确整数；份额为整数。

1. **连接与部署**：选择当前浏览器钱包；显示部署钱包及网络。读取本入口自己的编译产物和部署进度。部署确认弹窗展示待部署步骤数量和网络 Gas 提示，用户逐笔在钱包确认。部署中显示库与 sandbox 的步骤、已确认地址、交易链接，以及“继续剩余步骤”和“检查待确认交易”。不会自动重新发送已广播的步骤。
2. **测试项目**：显示模拟 NFT、项目状态、100 份总份额、当前钱包份额、可领 BNB。部署完成后可把整数份额分配给其他测试钱包，以测试持有人数和份额双多数。地址和完整清单默认折叠，可导出 JSON。
3. **出售提案**：输入出售价格和测试参考价，读取合约的实际冷却时间及当前提案。可显示未满足的冷却条件和剩余秒数。当前提案显示出售价格、参考价、低价审核状态、赞成份额和赞成人数门槛。参考价为模拟测试数据，页面不会读取或改写正式 Firsto 报价。
4. **审核与投票**：管理员钱包可通过或拒绝低价出售；持有人钱包可赞成或反对。操作按钮根据当前合约状态和钱包身份显示。不得把“投票通过”显示成“可以执行”，执行仍受参考价、审核和合约期限限制。
5. **执行与买入**：执行通过的提案后显示挂牌价格、平台费、持有人净款和模拟 NFT。买方用自己的钱包确认精确 BNB 付款。买入后读取 NFT 新持有人和卖款状态。
6. **结算与领取**：最终 ABI 的 `withdrawBnb()` 在同一笔交易结算当前钱包售款并提现。界面只提供“领取我的 BNB”，可领金额为该钱包 `bnbOwed + pendingSaleProceeds`，包含它作为部署钱包应领的平台费。

## 小屏与交易反馈

桌面内容居中，手机单列，不依赖整站侧边栏。所有确认弹窗使用三个区域：标题、可滚动正文、始终可见的固定按钮栏；正文的地址和底层明细默认折叠。小屏也能直接看到“取消”和“在钱包确认”。

钱包请求等待、已广播等待、成功、链上失败和用户拒绝分别显示。广播得到 hash 不代表成功；RPC 读取失败保持等待状态，不误报链上失败。成功和失败结果弹窗使用精简中文原因及完整 hash 的 BscScan 链接；无 hash 的钱包拒绝不显示交易链接。关闭结果不会重复发送或重复弹出已恢复的历史结果。

## 隔离和部署记录

- 不调用正式 `/bemine-v4/api/journal`、链上索引、Authority relay 或 Gas signer。
- 使用独立静态资源目录、测试 artifact digest 和测试 manifest，默认文件名 `sale-sandbox-artifacts.json`。
- 钱包发送的合约创建字节码必须来自本入口编译产物。业务写入目标只来自已完成的本次测试 manifest；不能输入任意矿池或 NFT 地址。
- localStorage 前缀为 `bemine-sale-sandbox:v1:`，包含 chainId、网站 origin、artifact digest 和部署钱包；支持导入/导出同一测试清单以便其他持有人或买方钱包参与。
- 待确认记录保存步骤、发送钱包、hash、目标、calldata、value。切换钱包不丢失部署记录，但停止旧钱包操作并清除未发送的预览。
- 主网创建交易只由当前连接的钱包发起。公开入口无私钥，不接受正式 signer 凭证，不把测试角色映射到正式管理员服务。

## 最终 ABI 约定

构造参数为 `(address testOwner, address[] initialMembers, uint8[] initialShares, uint128 simulatedPurchaseCost)`；testOwner 固定当前部署钱包。两个正式链接库为 ShareCheckpoints 与 SaleSettlement，治理副本 internal 内联。其他业务接口读取 SandboxSalePool ABI。

constructor 自建 MockNFT，部署步骤为两个 linked libraries 加 sandbox，共三笔。投票、挂牌和冷却时长读取测试合约 getters，不复用正式页面的 86400 秒或七天校验。双多数通过且参考价与审核满足后，可在投票截止前即时执行；不得误加“必须等投票结束”的条件。默认 0.00001 BNB，所有模拟参考价与出售金额均不超过 0.00100 BNB。

## 浏览器验证范围

独立 localhost fixture 模拟钱包和回执，禁止真实网络发送。验证逐步部署及拒绝恢复、精确库链接、钱包切换、历史清单恢复、低价审核前后的执行门槛、双多数投票、精确买款、结算与领取区分、结果去重、375px 短屏确认按钮可见，以及没有请求正式 API。
